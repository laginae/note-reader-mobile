# Cozy Read Aloud Mobile 0.3.13

- Match desktop concise subscript speech: `r_t` reads "r t", `r_{t+1}` reads "r t plus 1", and `x_{i,j}` reads "x i j".
- Keep "subscript" / "下标" in verbose style and structural cues for compound indices. Smart-mode formula omission and superscripts are unchanged.
- Use the same formula conversion for Markdown, local HTML and PDF speech.
- Verified with automated synthetic-text tests and the mobile dependency boundary check; this release has not been tested on a physical iOS device.
- No personal documents or credentials are included.
