# Note and PDF Voice Reader for Mobile

[English](README.md) | [简体中文](README.zh-CN.md)

这是面向 Obsidian 手机和平板端的笔记、PDF 与本地 HTML 朗读插件。

**0.3.1 为移动端早期版本。** 已有 iPhone 用户确认：全文朗读、选中文字起读、暂停/继续、停止、倍速及工具栏无遮挡，在其测试环境中正常。新增的大纲、脚注、HTML 和导出流程仍需扩大真机验证；复杂 PDF 的部分场景可能存在问题。这是独立插件，不修改或替换桌面版。

## 功能亮点

- **边看边听：** 触控播放条提供暂停、停止、倍速与当前音频进度控制。
- **学术 PDF 阅读：** 单双栏排序、页眉页脚过滤和保守的脚注分离，兼顾首页作者信息。
- **大纲定位与章节朗读：** 支持 Markdown 标题、HTML 标题和 PDF 书签/自动识别标题。点击标题定位正文，单独选择朗读本节或从本节继续。
- **完整句子优先：** 放不下的句子移到下一段，只有句子本身超长时按分句或词边界拆分；保守合并 PDF 跨页续句，不突破语音接口保护上限。
- **本地 HTML：** 配合 HTML Reader，支持全文、选中文字及从选中位置朗读。
- **WAV 导出：** 明确确认后，将在线引擎的朗读范围保存为仓库内音频。
- **隐私选择：** 默认系统语音，在线服务需要授权；没有开发者中转服务器或内置遥测。

## 安装与开始

1. 使用 Obsidian 1.11.4 或更高版本，并先备份仓库。
2. 打开 **设置 → 第三方插件 → 浏览**，搜索 **Note and PDF Voice Reader for Mobile**。
3. 点击 **安装**，然后 **启用**。也可以打开[社区介绍页面](https://community.obsidian.md/plugins/note-reader-mobile)。
4. 打开笔记或 PDF，点击朗读图标显示播放工具栏。
5. 先尝试系统语音；也可以在插件设置中配置在线服务的秘密，并明确允许在线处理。

如需浏览和朗读本地 HTML 文件，请另外安装并启用 **HTML Reader**。请避免在同一仓库同时启动桌面版和移动版朗读。

## 当前功能

### 手机端控制

点击朗读图标或运行“Show reading toolbar”命令，在当前笔记或 PDF 的标题栏下方、正文上方打开播放条，不再默认切换到独立面板。播放条在正文滚动区域之外独立占位，避开 iOS 悬浮底部导航。选择朗读范围后点播放；暂停、继续、上一段、下一段、当前音频进度和倍速都可直接操作。进度条只定位已加载的音频，系统语音不支持拖动定位。

播放按钮旁的方形“停止”按钮可结束朗读或取消 PDF 解析，并保留播放条。播放条右上角可展开完整面板。面板左上角的返回箭头回到正文并保留播放，关闭按钮则停止并收起朗读器。选中文字后可选择“从选中位置继续”；打开面板前会临时保留选区，修改正文后请重新选择。选区仅保存在内存，不写入配置。停止不能撤回已发给服务商的语音请求或其计费。

手机上打开播放条时，当前页签的原生标题按钮会暂时参与正常排版，并预留状态栏安全区；关闭后恢复原布局。iPad 按页签宽度自适应：宽页签单行排列，分屏或台前调度的窄窗口使用多行排列，不重复添加手机专用的状态栏留白。仍需继续在 iOS/Android 真机验证，尤其是旋转、键盘、原生选区菜单与不同 PDF 视图的配合。

- 朗读笔记或 PDF 中选中的文字
- 从选中位置继续朗读
- 朗读当前完整笔记或文本型 PDF
- 从仅包含短文本锚点的保存位置继续朗读
- 按坐标识别 PDF 单栏、双栏和单双栏混合排版
- 默认开启本地 PDF 页眉页脚过滤，可在设置中关闭
- PDF 书签或自动识别大纲、按章节朗读，以及仅缓存一份 PDF 的内存大纲缓存
- PDF 只读正文、保留原顺序或只读脚注
- 本地 HTML 朗读，以及在线语音的确认式 WAV 导出
- 默认使用设备系统语音，插件不会向在线 TTS 服务发送文本
- 可选小米 MiMo、Azure Speech、OpenRouter TTS、HTTPS 远程 CosyVoice 和自定义语音 API（BYOK）
- 适合触控和竖屏的控制界面，可暂停、继续和跳转分段
- 在线语音严格按需合成当前分段，不提前合成后续段落
- 在线音频本地倍速、音量与当前已加载音频内定位
- 分类设置、学术文本处理，以及不改变逻辑段编号的渐进式起读音频

## 在线服务配置

**通过 OpenRouter 使用 ElevenLabs：** 提供 Multilingual v2、Flash v2.5、Eleven v4 和 v4 Turbo，以及 George、Sarah、Daniel、Alice、Brian、Lily 六个音色，原有默认值不变。以 MP3、正常语速合成，收听时在播放器调整倍速。仍强制 ZDR 并禁止数据收集，无可用路由时失败，不降低隐私限制。已于 2026-10-08 核对 [语音目录](https://openrouter.ai/api/v1/models?output_modalities=speech)和 [ZDR 端点列表](https://openrouter.ai/api/v1/endpoints/zdr)，价格与可用性可能变化。

**可选分段衔接：** 选择以上四个模型后，显示“ElevenLabs 高级选项”，其中“改善分段衔接”为默认关闭的实验功能。开启后，通过 `provider.options.elevenlabs` 发送当前朗读范围内的相邻句子，每侧最多 160 字符；不会读取选区外内容，也不使用历史请求。切换到其他模型时隐藏此项、不发送相关参数，但保留偏好。不上传云端发音词典，不自动添加表演标签；原文已有语音标签可能影响语气。参数依据 [OpenRouter 官方公告](https://openrouter.ai/blog/announcements/elevenlabs-on-openrouter/)，尚未进行付费试听，不保证改善效果。

**本地术语读法：** 在“学术阅读”中开启，按行填写 `BESS = B E S S`。规则区分大小写、按字面匹配，不支持正则；较长术语优先，不递归替换。最多 100 条，术语最多 80 字符、读法最多 120 字符。规则保存在本地；在线引擎仍会收到替换后的朗读文本，但不会收到完整规则列表。原文件与原文定位保持不变，展开后的请求会按引擎限制再分段。规则也用于音频导出，下次朗读生效，不改动已合成的音频。

**小米 MiMo：** 在 [MiMo 控制台](https://platform.xiaomimimo.com/) 获取 API 密钥，通过 Obsidian 秘密选择器保存和关联，然后允许在线处理。默认使用**白桦**，可尝试中英文朗读。采用保守的 200 字符分段，未确认完整生成时停止而不跳段。这是插件限制，不是官方公布的接口上限。价格和优惠可能变化，不承诺永久免费。详见 [官方语音合成指南](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。

**OpenRouter：** 选择秘密、模型、音色，再允许处理。**Azure：** 还需填写 Speech 资源区域和云环境。请核对资源或服务商适用的隐私与保留政策；填写密钥不代表插件认证了“不训练”或“ZDR”。

**BYOK：** 支持一个当前配置，类型包括 OpenAI 兼容语音接口、ElevenLabs、MiniMax。填写地址、模型、音色 ID 和秘密引用后，需要明确确认传输、计费、训练及保留风险。修改地址或服务商会清除秘密引用和授权，但不会删除已保存的秘密；修改模型、音色和秘密引用也需重新授权。仅支持聊天的接口不能当作语音接口使用。

BYOK 和远程 CosyVoice 使用 HTTPS、拒绝重定向、不携带 Cookie，不会退回绕过这些限制的方式。接口必须允许移动 WebView 的跨域请求（CORS），部分服务可能不可用，需以实际手机和接口验证为准。用户授权不是服务商隐私保证，撤销也不能收回已发送的文本。

音色与接口参考：[OpenAI](https://developers.openai.com/api/docs/guides/text-to-speech)、[ElevenLabs](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)、[MiniMax](https://platform.minimax.io/docs/api-reference/speech-t2a-http)。

## 隐私边界

默认的系统语音模式不会由本插件发起 TTS 网络请求，但操作系统及音色实现决定其自身是否联网。重视隐私时优先选择标记为本地的音色。安装的音色不一定会向移动 WebView 开放。所有在线模式都必须主动允许，且仅发送当前需要播放的文本。

API 密钥保存在 Obsidian SecretStorage 中，`data.json` 只记录秘密名称。OpenRouter 请求固定要求 ZDR 并拒绝供应商收集数据，无合适路由时会失败而不会静默降低要求。PDF 文本提取和阅读顺序计算在本地完成。

插件没有开发者中转服务器，也没有内置遥测。音频保留在内存中播放；设置及可选续读记录保存在仓库，可能被用户选择的同步服务同步。操作系统、Obsidian 和服务商另有各自政策。停止或超时不能撤销已开始的服务端处理或计费。插件不自动重试失败请求，也不在提示中展示可能包含正文的原始服务响应。

OpenRouter 默认使用 Kokoro 英式男声 `bm_george`，也包含美式英语预设。微软兼容音色即使在某一路由可用，也可能被另一路由拒绝。模型、音色、账户权限及价格以服务商实际情况为准。

## PDF 大纲与脚注

打开 Markdown、HTML 或 PDF 后，点击工具栏大纲图标，或在完整播放器选择“文档大纲”。点击标题定位原文并关闭大纲，不改变正在播放的音频。点击标题右侧的范围图标选中章节，再选择“朗读本节”或“从本节继续”；本节包含下级章节，到下一个同级或更高层级标题前停止。Markdown 使用标题层级，HTML 使用 h1–h6（保留标题中的编号，需要 HTML Reader 显示原文）。PDF 优先书签，否则自动识别；不支持精确定位的 PDF 视图退回对应页并提示。HTML 无法可靠定位时保留面板并提示，不猜测位置。

同一未修改 PDF 再次打开大纲时使用内存缓存，点刷新才重新识别；文件或页眉过滤设置变化会使缓存失效。仅保留一份 PDF 的缓存，不写入配置，插件卸载或重启后清除。不向 PDF 写回书签。

“学术阅读 → PDF 脚注朗读”默认“只读正文”，结合页底标号、小字号和明显间距识别脚注及首页作者信息；不确定的内容保留。也可选择“保留原顺序（含脚注）”或“只读脚注”。工具栏朗读范围菜单另有“只读 PDF 脚注”快捷入口，不修改默认设置。仅朗读选中文字时保留所选内容。脚注按页面排版分离，不自动判断其对应的正文引用。

## 本地 HTML

先安装并启用 **HTML Reader** 社区插件，以打开仓库内 `.html` 或 `.htm` 文件。全文朗读在本地解析已保存的 HTML，不执行脚本、不加载页面资源；HTML Reader 内嵌页面可访问时，选中文字及选中位置朗读按实际选区处理。页面重载或文件修改后可能需要重新选择。仅由脚本动态生成、未保存在文件中的内容不属于全文提取范围；暂不支持外部网页或 HTML 高亮。

## 音频导出

使用在线引擎开始一个朗读范围后，展开播放器，点击“导出朗读音频”（也可使用命令），核对分段数及字符数后确认。导出会重新合成该范围的全部分段，不只是剩余部分，可能产生额外费用；当前播放会暂停，服务授权仍然有效。

输出为原速、单声道 16-bit WAV，保存在仓库 `Note Reader Audio/`，不叠加播放器倍速或音量。不依赖桌面程序，不覆盖已有文件；导出内容可能被仓库同步服务同步。关闭导出窗口可取消后续合成，但无法撤回已发请求或已开始的文件写入。系统语音不支持导出。移动端限制为 30,000 字符和 32 MiB 音频，超限时需改用更短选区或章节；失败或超限不会生成完整导出文件，但已发送的合成请求仍可能计费。

## 播放与适用边界

简单公式如 `$z_{\mathrm d}$` 会读作“z sub d”。字体和排版空白不会使简单公式被误判为复杂公式；仍尊重主动跳过公式的设置，并保留复杂公式保护。

常见上下界写法如 `[\ell,u]`、以同一变量的 `E_{\min}` / `E_{\max}` 开头的两端表达式，精简模式使用“到”，详细模式保留“闭区间”提示。其他方括号对仍按括号朗读；相邻的简单带下标变量之间补读“乘以”。

**PDF 页眉页脚：** 在“设置 → 学术阅读 → 跳过 PDF 页眉页脚”中控制，默认开启。在本地过滤页边重复短行（如作者、期刊名）及可识别的页码，不修改原 PDF。适用于整篇朗读、从选中位置继续和从上次位置续读；“朗读选中文字”保留所选文字。修改设置在下次朗读时生效。

采用保守识别，保留无法确定的页边文字、较大字号标题及编号标题。从中间页开始时，最多额外参考前 3 页识别重复信息，但不会朗读这些参考页。独有页眉、非常规边距、旋转页面或缺少坐标的文本可能仍被读出；若发现正文误删，请关闭此设置。

## 手动安装

社区目录无法访问，或需要安装特定版本时，可使用此备用方式。

1. 从 [GitHub Releases](https://github.com/laginae/note-reader-mobile/releases) 的同一版本下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 使用设备文件管理器或仓库同步，将三个文件放入 `<仓库>/.obsidian/plugins/note-reader-mobile/`。
3. 在第三方插件设置中启用插件。手动更新已启用的插件后，请关闭再开启，让新文件生效。

不要复制其他仓库的 `data.json` 或密钥。社区审核通过不代表所有设备和文档场景均已测试通过。
