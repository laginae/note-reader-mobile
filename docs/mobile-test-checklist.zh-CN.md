# 移动端建议测试清单

适用版本：Cozy Read Aloud Mobile 0.4.2。编写日期：2026-10-29。

**当前状态：本轮尚未进行 iPhone、iPad 或 Android 真机验收。** 自动化测试、桌面移动布局模拟和过去版本的反馈均不能代替本清单。后台播放仍为实验性功能，默认关闭。

## 测试准备

- 先备份库。使用单独的测试笔记，只开启移动版朗读插件，避免与桌面版同时播放。
- 使用 [公开示例笔记](mobile-public-sample.md)。PDF 可用任意允许公开的双栏文档，避免论文草稿、个人信息或工作材料。
- 首轮优先使用系统语音。在线测试需自行确认发送范围、提供方隐私政策和小额预算；不要在反馈中附密钥。
- 记录：日期、设备型号、系统版本、Obsidian 版本、插件版本、主题、语音引擎与音色、预取开关。
- 每项标记「通过 / 失败 / 未测 / 不适用」，写下具体观察。不应因没有设备而标记通过。

## 第一轮：约 10 分钟

| 编号 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| A01 | 打开示例笔记，显示工具栏，再展开完整面板 | 工具栏不与状态栏或底部导航重叠；面板可滚动到最后一项 | 未测 |
| A02 | 全文朗读，连续听完前三段 | 顺序正确；不重复首句、不漏句；进度随段落变化 | 未测 |
| A03 | 选中一句，打开面板后选择「朗读选中文字」 | 只读选中的句子，不擅自读完整段或全文 | 未测 |
| A04 | 选中第二段中间一句，选择从选中位置继续 | 从该句开始，之后顺序继续；不回到第一段 | 未测 |
| A05 | 暂停 5 秒后继续，重复 3 次 | 接续同一音频；不循环一句、不出现旧声音重叠 | 未测 |
| A06 | 连续点下一段、上一段，然后停止 | 最后一次操作生效；停止后迟到请求不会自动发声 | 未测 |
| A07 | 切换 1x、1.5x、2x | 已加载在线音频跟随倍速；系统语音可能从下一段应用 | 未测 |
| A08 | 开关高亮，暂停，再跳到下一段 | 高亮可关闭；暂停保留当前段，跳转后更新；不拦截选中文字 | 未测 |
| A09 | 打开大纲，点击第二个标题 | 返回对应标题位置，标题不被工具栏遮住；仅定位不自动播放 | 未测 |
| A10 | 返回文档、关闭工具栏，重新打开 | 返回不意外停播；关闭按界面定义停止；重新打开正常 | 未测 |

## 第二轮：PDF 与 HTML

| 编号 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| B01 | 同一 PDF 分别全文读、选中读、章节读 | 共用公式处理规则；不因选区路径读出乱码或段外正文 | 未测 |
| B02 | 在双栏 PDF 选中右栏一句，并从这里继续 | 从准确位置开始，不先读左栏；跨页时不漏段或重读 | 未测 |
| B03 | 选择有重复句子的第二处；另试局部单词选区 | 保持该处来源；无法可靠定位时提示重新选择，不猜位置 | 未测 |
| B04 | 智能模式阅读短变量、复杂独立公式和希腊字母 | 简短变量保留，复杂公式概括略过，提示语言跟随正文 | 未测 |
| B05 | 页眉页脚过滤开/关对比 | 重复边缘文字可过滤，正文不丢失；明确选中的页脚仍可读 | 未测 |
| B06 | 对有脚注的公开 PDF 切换正文、全文顺序、仅脚注 | 变化符合范围；普通编号段落不应无故消失；原 PDF 不被修改 | 未测 |
| B07 | PDF 缩放、转屏、切页、换文件 | 高亮保持对应来源，失去可靠定位时不显示错误旧框 | 未测 |
| B08 | 大 PDF 解析中按停止，再打开另一文件 | 不继续播放旧文件；新文件可以正常使用 | 未测 |
| B09 | 安装 HTML Reader，打开公开本地 HTML，全文/选中/从选区读 | 范围正确；页面刷新后旧选区失效；不可访问的页面明确失败 | 未测 |
| B10 | 在线引擎导出短公开选区，确认后播放生成 WAV | 内容和范围正确，取消不会继续新增后续请求；失败不输出伪完整文件 | 未测 |

本版移动端高亮是段落级标记，不是逐字同步，也不保证自动滚动。网页端的新段内自动跟随不等于移动插件已经支持相同行为。

## 第三轮：设备、网络与中断

| 编号 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| C01 | 手机竖屏/横屏、键盘打开/收起、深浅主题 | 所有按钮和最后一行可到达，文字无重叠 | 未测 |
| C02 | iPad 全屏、窄分屏；有条件再测 Stage Manager | 根据窗口宽度调整，窄窗口仍可关闭面板和操作播放 | 未测 |
| C03 | 合成时暂停，等待请求完成，再继续 | 等待完成不自行发声；继续只播放当前段 | 未测 |
| C04 | 合成时换文件/音色/引擎，或撤销在线授权 | 旧响应不接管新会话；撤销后不新发请求 | 未测 |
| C05 | 暂时断网，之后恢复并手动重试 | 有可理解错误，不无限重试、不误报必然额度不足 | 未测 |
| C06 | 开启预取后暂停/停止；在设置中清理缓存 | 不再安排新预取；清理后仍可重新朗读。已发送的请求可能计费 | 未测 |
| C07 | 默认设置下切后台 15 秒、锁屏 15 秒，再回来 | 允许系统暂停；不得两段同时播放、循环、失去停止按钮 | 未测 |
| C08 | 耳机断开、系统音频打断、来电后返回 | 不出现意外重复或过期音频；应能手动继续/停止 | 未测 |
| C09 | 自愿开启实验性后台选项，仅用短公开文本测试 | 单独记录是否连续、何时中断；不把短测通过当作后台播放保证 | 未测 |
| C10 | 禁用并重新启用插件、重启 Obsidian | 无旧音频残留；密钥和原有配置不被无故覆盖 | 未测 |

不必为测试实际拨打电话；可记录自然发生的中断。无需反复执行收费失败请求。

## 反馈模板

在 [GitHub Issues](https://github.com/laginae/note-reader-mobile/issues) 提交：

```text
测试编号：
插件 / Obsidian / 系统版本：
设备与屏幕方向：
引擎、音色、预取 / 后台开关：
复现步骤（尽量 3–5 步）：
预期结果：
实际结果：
发生比例（例如 5 次中 2 次）：
是否只在某一公开文件出现：
```

截图只保留控制界面、必要公开正文及 PDF 位置，遮掉账号、路径、密钥与私人笔记。不要上传 `data.json`、完整请求日志或私密论文。优先提供能复现的小型公开示例。

## 发布判断

若出现越界朗读、停止后继续发声、循环重复、界面无法退出、误泄露正文/密钥，视为阻断问题，先停止使用相关路径并反馈。单个特殊 PDF 的保守不高亮或公式略过，应记录范围和样例，不宜宣称所有 PDF 都失效。设备测试未完成时继续保留「未测」，不承诺后台和锁屏稳定性。
